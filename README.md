Игра Камень-Ножницы-Бумага

## Описание
Учебный проект, реализующий классическую игру "Камень, Ножницы, Бумага" на языке Python. 
Игрок соревнуется с компьютером, делая выбор между тремя вариантами. Правила просты: 
камень побеждает ножницы, ножницы побеждают бумагу, бумага побеждает камень. 
Проект создан в учебных целях для отработки навыков работы с Python и системой контроля версий Git.

## Как играть
1. Убедитесь, что на вашем компьютере установлен Python (версии 3.6 или выше).
2. Откройте терминал (командную строку) и перейдите в папку с проектом.
3. Запустите игру командой:
   ```bash
   python game.py

## Функциональность
Выбор хода пользователя с проверкой корректности ввода (защита от опечаток и невалидных значений).
Случайный выбор хода компьютера из трёх возможных вариантов.
Автоматическое определение победителя по классическим правилам игры.
Система подсчёта очков:
Отдельные счётчики для побед игрока, побед компьютера и ничьих.
Автоматическое сохранение результатов в файл score.txt после каждого раунда.
Загрузка предыдущего счёта при запуске игры (результаты сохраняются между сессиями).
Возможность выхода из игры в любой момент по команде выход.
Дружелюбный интерфейс с понятными сообщениями для пользователя.

## Требования
Python 3.6 или выше.
Стандартные библиотеки Python (устанавливаются вместе с интерпретатором):
random — для генерации случайного выбора компьютера.
os — для работы с файловой системой (сохранение и загрузка счёта).
Дополнительные внешние зависимости не требуются.
